# Contributing

Thanks for helping improve this project.

## Getting started

- Review the top-level [README.md](README.md) and [SETUP.md](SETUP.md) for build and environment guidance.
- Use the root [Makefile](Makefile) for common local tasks such as building and testing.
- For container-based work, use [Dockerfile](Dockerfile) and [docker-compose.yml](docker-compose.yml).

## Development workflow

1. Create a branch for your change.
2. Make focused updates and keep the scope narrow.
3. Run the relevant build or test commands before submitting a pull request.
4. Update documentation when behavior or workflow changes.

## Code style

- Follow the existing CMake, C++, Rust, Go, and Python conventions in the repository.
- Keep changes readable and well-documented.
- Prefer small, reviewable pull requests.
